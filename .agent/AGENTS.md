# 儲存庫內 Codex 代理規則

## 語言

- 回覆、計畫、Issue、PR、審查、提交訊息與文件散文使用繁體中文。
- 程式碼識別字、命令、路徑、URL、JSON key 與官方產品名稱保留原文。

## 邊界

- 根目錄 `AGENTS.md` 優先於本文件。
- 主行程資料、研究、規劃、最佳化、驗證與呈現邊界不得被代理繞過。
- `vendor/agentic-dev-collaboration/` 是固定版本快照，不得直接修改。
- 專案代理只能透過 `agent-collaboration/` 覆寫；不得把個人帳號、存取憑證、工作階段或機器狀態提交到儲存庫。

## 工作方式

- 產品變更使用隔離工作樹，不在主簽出目錄實作。
- 先以工具取得目前狀態，再提出事實性結論。
- 每次推送都要以新的精確提交頂端重新取得 CI 與獨立審查證據。
- 未經使用者授權，不執行 merge、部署或其他外部狀態變更。
