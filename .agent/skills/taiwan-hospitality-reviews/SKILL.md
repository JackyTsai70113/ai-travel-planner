# 台灣住宿與餐飲評價研究

先取得地點、日期、預算、房型或用餐人數、旅客限制與優先順序。飯店空房與餐廳訂位是動態資訊，評價研究不構成可預訂承諾。

## 來源與比較

1. 優先使用合規的供應商 API 或公開可引用的飯店／餐廳評價頁，記錄平台、評分原始尺度、評論數、擷取時間與直接 URL。沒有足夠資料時明確標示缺口，不要補成零或估算值。
2. 評分只在相同平台、相同尺度且評論量與時效合理時比較；不同平台的星等與分數不可直接排序。不要從原始 payload、受限評論或未授權抓取內容建立資料集。
3. 以近期且可取得的評價摘要辨識重複出現的優點與摩擦，例如隔音、清潔、親子設施、停車、排隊、服務速度或無障礙。將它們標示為 `community-experience`，並附來源與時間；單一負評或正評不可推導普遍結論。
4. 住宿地址、入住規則、價格、空房、餐廳營業時間、特殊休假與訂位規則，必須回到飯店、餐廳或訂位負責方的官方頁／搜尋結果確認。評價不能覆寫官方營運事實。

## 輸出

每個候選提供：名稱與地點、平台評分（含尺度）、評論數、擷取時間、近期重複主題、適合與不適合的旅客情境、官方營運確認狀態，以及各自 URL。將品質評價與營運事實分欄；發生衝突時保留兩者並以官方資料決定硬性限制。

評價資料只能影響候選的軟性排序。排入行程前，住宿與餐廳仍要通過既有的預算、交通、營業時間與確定性驗證；未知或衝突營業時間不可視為營業中。
