# 台灣官方活動研究

先取得目的地、旅行日期、旅客限制與想找的活動類型。日期或地點不明時，先詢問；不要以「本週」等相對日期猜測旅行日。

## 搜尋與確認

1. 先找交通部觀光署／旅遊資訊網、縣市觀光單位與活動主辦方；再找景區、博物館、表演場館或展覽的直接官方頁。搜尋結果頁與轉載新聞只能用來發現候選，不能當作活動是否舉行的依據。
2. 對每個候選確認實際舉辦日期與時間、地點、票價或預約、年齡／無障礙限制、停辦或入場規則。若活動頁沒有明示旅行日期的適用性，標示為待確認，不要排進確定行程。
3. 活動跨多日或有場次時，保留適用場次與時區 `Asia/Taipei`。活動名稱相同但年份不同時，只採用明示年份或日期的公告。
4. 每個可用事實都記錄官方來源 URL、來源名稱與 `retrieved_at`。記錄最小必要摘述，不複製整頁內容，也不繞過登入、CAPTCHA、robots 或網站條款。

## 輸出

依決策用途列出：活動、適用日期／時段、地點、是否適合旅客、費用／預約、官方 URL、查詢時間，以及狀態（`confirmed`、`unverified`、`stale` 或 `contradictory`）。另列出因日期、公告衝突或規則缺失而沒有採用的候選與原因。

官方活動只能提供候選與營運事實；行程排序仍須交給既有研究、規劃、最佳化與驗證流程。對臨時停辦、管制、天候型活動與最後入場時間採用短時效，過期後回報未知並重新查核。
