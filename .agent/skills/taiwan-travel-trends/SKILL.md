# 台灣旅遊趨勢研究

先取得目的地範圍、旅行月份、旅客組成、交通方式與偏好。趨勢只回答「近期可能值得研究什麼」，不是行程可執行性的證明。

## 蒐集與判讀

1. 搜尋近期的台灣旅遊內容、地方旅遊單位主題頁、公開趨勢工具可見的查詢熱度，以及近期影片／文章的反覆主題。每個訊號保留發布或觀察日期、地理範圍與來源 URL。
2. 將訊號分成 `official-promotion`、`search-interest`、`publisher-coverage` 或 `community-experience`；不要把不同類型或不同期間的數字合併成排名，也不要宣稱不具代表性的內容是「大家都去」。
3. 只在至少兩個獨立且近期的訊號支持時，將景點、街區、季節活動或體驗列為高優先研究候選。單一影片、單一貼文或業配內容只能列為探索線索。
4. 對每個高優先候選，以主辦方或場館官網重新確認開放日、活動日期、預約與交通限制；未確認前不得把趨勢訊號當作可排入行程的事實。

## 輸出

以「候選主題 → 支持訊號 → 旅客適配性 → 可能摩擦 → 需官方確認事項」呈現。每項附來源 URL、內容或觀察日期與 `retrieved_at`，並清楚標示證據類型與信心。

不要抓取登入後內容、留言全文、逐字稿或未授權資料集；不要以趨勢作為營業時間、票價、可訂位或安全狀態的替代資料。後續若進入行程，保留趨勢資料為軟性偏好，將官方營運事實分開記錄。
